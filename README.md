# Oralingo

Обучающее веб-приложение в стиле Duolingo (18+): курс по технике оральных ласк.

- 11 разделов, 74 урока: согласие, безопасность, анатомия, основы, работа руками,
  тренировка горла и рвотного рефлекса, продвинутые техники, мастерство,
  расслабление, упражнения для рта и горла, лайфхаки.
- В каждом уроке теория и тест; ошибочные ответы возвращаются в конец урока.
- 71 практическое задание: чек-лист, письменный отчёт и оценка. Отчёты попадают в дневник.
- Вкладка «Практика» — все задания сразу; «Техники» — справочник всей теории.
- Все уроки открыты сразу, есть опыт (XP) и серия дней подряд. Прогресс хранится в localStorage.

## Запуск
Откройте `app/index.html` в браузере. Сборка и сервер не нужны.
