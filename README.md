# Oralingo

Обучающее веб-приложение в стиле Duolingo (18+): курс по технике оральных ласк.

- 11 разделов, 74 урока: согласие, безопасность, анатомия, основы, работа руками,
  тренировка горла и рвотного рефлекса, продвинутые техники, мастерство,
  расслабление, упражнения для рта и горла, лайфхаки.
- В каждом уроке теория и тест; ошибочные ответы возвращаются в конец урока.
- 71 практическое задание: чек-лист и оценка, выполненное попадает в «Историю».
- Ежедневная тренировка рвотного рефлекса: каждый день новый набор из 31 упражнения, таймер,
  3 уровня сложности, график чувствительности за 14 дней.
- Вкладка «Практика» — все задания сразу; «Техники» — справочник всей теории.
- Все уроки открыты сразу, есть опыт (XP) и серия дней подряд. Прогресс хранится в localStorage.

- Вкладка «Тренер» (20 инструментов): тренировки рефлекса и челюсти, разминка 3 мин, вызов недели,
  сессии с партнёром, конструктор связок, метроном, кубик, карточки для разговора, список «Хотим попробовать»,
  анкета «Узнай партнёра», памятка для партнёра, повторение, «Найди ошибку», мифы и факты, схемы, словарь,
  справочник техник, личные рекорды, дневник ощущений.
- Профиль: карта навыков, 33 достижения, цель дня, напоминания через календарь (.ics), напоминание об анализах,
  PIN-код, тёмная тема, скрытый режим, экспорт/импорт прогресса. Устанавливается на главный экран (PWA, работает офлайн).

## Запуск
Откройте `app/index.html` в браузере. Сборка и сервер не нужны.
